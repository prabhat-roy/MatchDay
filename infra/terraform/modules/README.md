# Modules

Cross-cloud reusable Terraform modules.

| Module | Purpose |
|---|---|
| `kafka-topics/` | Strimzi/MSK/Event Hubs topic provisioning from a single list |
| `kms-key-pair/` | Issues a (general, anti-doping) KMS key pair on each cloud |
| `gitops-bootstrap/` | Installs ArgoCD + ApplicationSet root |
